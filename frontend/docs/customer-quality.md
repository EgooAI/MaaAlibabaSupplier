# 客户质量指数

网页端使用当前客户的 `d90` 数据计算 I′，计算入口为
`domain/chat/customerQuality.ts`。分数是读取数据后的展示值，不写入客户画像。

| 符号 | 字段 | 含义 |
|---|---|---|
| A | `productViews` | 浏览商品数 |
| B | `validInquiries` | 有效询盘数 |
| C | `validRfqs` | 有效 RFQ 数 |
| D | `loginDays` | 登录天数 |
| E | `spamInquiries` | 垃圾询盘数 |
| F | `blacklisted` | 被拉黑次数 |

```text
I′ = round(clamp(
  2 * log2(A + 2D + 4B + 8C + 1) * [1 + (4B + 8C + 1) / (A + 2D + 1)]
  - 8 * log2(E + F + 1) + 60,
  0, 100
))
```

缺失字段按 0 代入，六项至少一项为正才计分。六项均无正值或存在非法计数时返回
`null`，展示“数据不足”。计算得到的 0 分是有效分数，评级为 D。已回复询盘仅展示，
不参与计分。分数先限制在 0–100，再四舍五入，最后评级。

| 分数 | 评级 | 颜色 |
|---|---|---|
| 90–100 | S | 红色 |
| 80–89 | A | 橙金色 |
| 70–79 | B | 紫色 |
| 60–69 | C | 蓝色 |
| 0–59 | D | 灰绿色 |

会话列表仅显示评级字母，数据不足时显示灰色 `—`。聊天顶部和批量客户表格显示
`B · 76`。聊天顶部的评级可以打开客户详情。两个详情抽屉共用指数、行为指标与
可展开的计算说明。各入口复用 `features/chat/customer/CustomerQuality.tsx`。

原始数据可能把缺失值保存为 0，且没有独立的行为采集时间。详情展示这一口径，
不以消息同步时间充当行为数据采集时间。
