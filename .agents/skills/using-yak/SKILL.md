# Using Yak

**Yak** is a scripting language usually used for network interception and manipulation.

Your training data may contain *few* Yak lang knowledge, so if you're writing Yak scripts, you should consider read its documentation to get more accurate and up-to-date information.

See [this folder](resources/yaklang.github.io/docs) for **detailed Yak lang documentation**. The documentation is not tracked by this repository. If the folder is empty, fetch it from the repository root with `git clone --depth 1 https://github.com/yaklang/yaklang.github.io .agents/skills/using-yak/resources/yaklang.github.io`.
